# MiCash

Landing page for MiCash application.

## Tech Stack

- **Astro** - Web framework
- **Tailwind CSS** - Styling

## Project Structure

```
src/
├── components/     # UI components
├── layouts/       # Page layouts
├── pages/         # Route pages
├── styles/        # Global styles
└── assets/        # Static assets
```

## Commands

| Command       | Action                                        |
| :------------ | :-------------------------------------------- |
| `pnpm install` | Installs dependencies                         |
| `pnpm dev`    | Starts dev server at `localhost:4321`        |
| `pnpm build`  | Builds production site to `./dist/`           |
| `pnpm preview`| Previews build locally                        |

## Development

```sh
pnpm install
pnpm dev
```
